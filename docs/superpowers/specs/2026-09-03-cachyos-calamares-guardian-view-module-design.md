# Design Spec: CachyOS Calamares C++/Qt6 Guardian View Module

- **Date:** 2026-09-03
- **Status:** Approved
- **Author:** Parental-OS Core Engineering
- **Target Distribution:** CachyOS Desktop & Handheld (x86_64, aarch64)

---

## 1. Executive Summary & Objective

In Parental-OS CachyOS editions, the installer framework is **Calamares**. Currently, guardian secret persistence relies on an `exec`-phase Python job module that runs non-interactively during disk provisioning. Because no wizard UI prompted the user, installations default to an autogenerated random fallback secret.

This specification designs a genuine, native **C++/Qt6 Calamares ViewModule** (`calamares_viewmodule_guardian.so`) integrated directly into the Calamares installer wizard (`show:` sequence).

### Goals
1. **Integrated UI Step**: Provide a native Qt6 wizard page inside Calamares after the `users` step.
2. **Interactive Validation**: Solicit a "Guardian Password" with confirmation; disable the "Next" button until passwords match and are non-empty.
3. **Cryptographic Compatibility**: Compute the domain-separated SHA-256 hash using Qt's `QCryptographicHash`:
   $$\text{Hash} = \text{SHA256}(\text{"parental-guard:lan-v1:"} \parallel \text{password})$$
4. **Secure Target Provisioning**: Write the secret hash to `${targetRoot}/etc/parental-os/guardian.hash` with permissions `0600` and owner `root:root` (`0:0`), and update `/run/parental-os/guardian.hash` in the live environment.
5. **Standalone Compilation & Zero Upstream Forking**: Build as a standard Calamares Qt plugin against `cachyos-calamares-next` headers and libraries during containerized ISO assembly.

## 2. Architecture & Module Structure

The view module plugin will be structured under `distros/cachyos/calamares/viewmodule/`:

```
distros/cachyos/calamares/viewmodule/
├── CMakeLists.txt
├── module.desc
├── guardian.conf
├── GuardianViewStep.h
├── GuardianViewStep.cpp
├── GuardianPage.h
├── GuardianPage.cpp
├── GuardianJob.h
└── GuardianJob.cpp
```

### 2.1. Module Descriptor (`module.desc`)
```yaml
---
type: "viewmodule"
name: "guardian"
interface: "qtplugin"
load: "libcalamares_viewmodule_guardian.so"
```

### 2.2. Configuration File (`guardian.conf`)
```yaml
---
# Configuration for Parental-OS Guardian View Module
required: true
minLength: 4
```

## 3. Component Details

### 3.1. `GuardianPage` (`QWidget`)
A Qt6 widget implementing the user interface:
- **Layout**: `QVBoxLayout` with an informative header banner, a centered `QFormLayout`, and an error/status `QLabel`.
- **Inputs**:
  - `m_passwordField`: `QLineEdit` with `QLineEdit::Password` echo mode and clear button.
  - `m_confirmField`: `QLineEdit` with `QLineEdit::Password` echo mode and clear button.
  - `m_statusLabel`: Styled `QLabel` (red text) indicating errors (e.g., "Passwords do not match", "Password is required").
- **Signal**: `checkValidity()` emitted on `textChanged` signals from both fields.
- **Methods**:
  - `bool isValid() const`: Returns `true` only if `m_passwordField->text() == m_confirmField->text()` and `m_passwordField->text().length() >= minLength`.
  - `QString password() const`: Returns the verified plaintext password.

### 3.2. `GuardianViewStep` (`Calamares::ViewStep`)
Inherits `Calamares::ViewStep` and implements the Calamares view contract:
- `QString prettyName() const override`: Returns `tr("Parental Guard")`.
- `QWidget* widget() override`: Returns the `GuardianPage` instance.
- `bool isNextEnabled() const override`: Delegates to `m_widget->isValid()`.
- `bool isBackEnabled() const override`: Returns `true`.
- `bool isAtBeginning() const override`: Returns `true`.
- `bool isAtEnd() const override`: Returns `true`.
- `void onLeave() override`:
  - Retrieves the password from `m_widget`.
  - Computes the domain-separated SHA-256 hash:
    ```cpp
    QByteArray payload = "parental-guard:lan-v1:" + password.toUtf8();
    QString hash = QCryptographicHash::hash(payload, QCryptographicHash::Sha256).toHex().toLower();
    ```
  - Stores `guardianHash` in `Calamares::GlobalStorage::instance()`.
  - Writes `/run/parental-os/guardian.hash` in the live environment with mode `0600`.
- `Calamares::JobList jobs() const override`:
  - Returns a list containing a `GuardianJob` instance that persists the hash to the target root during the `exec:` installation phase.

### 3.3. `GuardianJob` (`Calamares::Job`)
Executes during the Calamares installation phase:
- Retrieves `guardianHash` from `Calamares::GlobalStorage`.
- Resolves the target root mount point via `Calamares::GlobalStorage::instance()->value("rootMountPoint").toString()`.
- Writes the hash to `${rootMountPoint}/etc/parental-os/guardian.hash`.
- Sets mode `0600` (`chmod`) and ownership `0:0` (`root:root`).
- Returns `Calamares::JobResult::ok()`.

## 4. Build System & ISO Packaging

### 4.1. CMake Build (`CMakeLists.txt`)
The plugin builds using standard CMake against `Qt6::Widgets`, `Calamares::calamares`, and `Calamares::calamaresui`.

### 4.2. Staging in CachyOS Builder
In `distros/cachyos/container/build-edition.sh`:
1. Compile the plugin using `cmake -B build -S ... && cmake --build build`.
2. Copy `libcalamares_viewmodule_guardian.so`, `module.desc`, and `guardian.conf` into:
   `/usr/lib/calamares/modules/guardian/`.
3. In `apply-parental-overlay.py`:
   Insert `guardian` into `sequence: - show:` immediately after `users`:
   ```yaml
   sequence:
   - show:
     - welcome@online
     - locale
     - keyboard
     - partition
     - packagechooser
     - netinstall
     - users
     - guardian
     - summary
   ```

## 5. Security & Verification Plan

1. **Permissions**: Mode `0600` and `0:0` ownership strictly enforced on target `/etc/parental-os/guardian.hash`.
2. **Domain Separation**: Exact string prefix `"parental-guard:lan-v1:"` matches agent and remote CLI tool.
3. **Automated Host Tests**:
   - Verify `CMakeLists.txt` builds without errors.
   - Verify `apply-parental-overlay.py` wires `guardian` into `show:` sequence of `settings.conf`.
   - Verify plugin binary exists in ISO staging.
4. **End-to-End QEMU Verification**:
   - Boot VM with CachyOS Desktop ISO.
   - Launch Calamares installer.
   - Verify "Parental Guard" page is displayed in the wizard.
   - Verify "Next" button is disabled until matching passwords are entered.
   - Complete installation, boot installed disk, and verify `/etc/parental-os/guardian.hash` exists and matches the password entered.
